# XtremIO

> XtremIO was an Israeli all-flash enterprise storage company founded in 2009 and acquired by EMC in May 2012 for $430 million; the technology continued as the Dell EMC XtremIO all-flash array product line. XtremIO no longer operates as an independent company and publishes no public developer program: xtremio.com is a parked domain (Safenames placeholder) retained under Dell brand protection.

This profile is part of the API Evangelist network catalog. XtremIO is tracked as a
venture-portfolio company (Battery Ventures, Lightspeed Venture Partners) that exited
by acquisition. The product's management REST API is documented by Dell for customers
of the appliance; there is no public, self-serve API surface to index for XtremIO itself.
